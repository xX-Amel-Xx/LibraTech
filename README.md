# LibraTech

Sistema web de gerenciamento de biblioteca desenvolvido com Python e Flask.

## Sobre o projeto

O LibraTech é uma aplicação web desenvolvida para facilitar o gerenciamento de uma biblioteca.

O sistema permite cadastrar livros, leitores, usuários e categorias, além de realizar empréstimos, devoluções e consultar o histórico de empréstimos.

O projeto foi desenvolvido com foco em aprendizado prático de desenvolvimento web, banco de dados e organização de aplicações utilizando Flask.

## Funcionalidades

- Cadastro de usuários
- Login e logout
- Recuperação de senha
- Cadastro de livros
- Cadastro de leitores
- Cadastro de categorias
- Registro de empréstimos
- Devolução de livros
- Consulta de livros disponíveis
- Histórico de empréstimos
- Filtro de empréstimos
- Controle do status dos empréstimos

## Tecnologias utilizadas

- Python
- Flask
- Flask-SQLAlchemy
- SQLAlchemy
- SQLite
- HTML5
- CSS3
- Jinja2
